# Home is the action surface: verdicts move books

**Status:** accepted

Home shows recommendations and is meant to be worked through, so it lists only **open** books — the current month's picks first, then anything still open from earlier issues; nothing expires. Pressing any verdict clears the book from Home instantly and files it: *want* → My Shelf, *read* / *loved* → the Archive, *not for me* → the Archive's set-aside. Reversals (put it back, mark unread, remove from My Shelf) return a book to Home as open. The design direction had decided books stay visible on Home with their verdict lit; that was rejected — a flip-able receipt keeps Home from being a to-do surface, and verdict changes belong in the sections where the book now lives. The old "still on your list" strip retires: Home itself carries the carry-over.
